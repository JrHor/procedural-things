A máquina de gerar números

Um computador por ser uma máquina exata é incapaz de criar ou escolher um número ou valor aleatório, por isso todo número aleatório é resultado de uma sequência numérica determinada por um cálculo matemático.

No livro "The C programming language" escrito por Brian Kerninghan e Dennis Ritchie é apresentado uma implementação de uma função de geracção de números pseudoaleatórios seguindo a seguinte fórmula

f(x) = ( ( x * 1103515245 + 12345 ) / 65536 ) mod 32768

onde x é o valor anterior da sequência numérica.
o primeiro valor x é o que chamamos de semente ou seed, o que determina que com esse valor, os próximos valores "aleatórios" sejam previsíveis.

Usaremos de exempĺo a seguinte função algébrica para gerar números de 0 a 100:

f(x) = ( x * 12345 ) mod 100
