Binary Space Partitioning (BSP)

O algoritmo BSP subdivide recursivamente o espaço euclidiano em hiperplanos convexos onde seu resultado final é uma estrutura de Árvore bsp.
Este é usado frequentemente para geração procedural de construções, masmorras ou salas aleatórias em jogos, como por exemplo no jogo Shattered Pixel Dungeon.
A versão a seguir do algoritmo é uma versão levemente modificada para demonstrar como seria essa geração de salas.
