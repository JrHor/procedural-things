A máquina de gerar números

Um computador, por ser uma máquina exata, é incapaz de criar ou escolher um número verdadeiramente aleatório. Por isso, todo número pseudoaleatório é resultado de uma sequência determinada por um cálculo matemático.

f(x) = ( ( x * 1103515245 + 12345 ) / 65536 ) mod 32768

Onde x é o valor anterior da sequência. O primeiro valor é chamado de semente (seed), o que torna a sequência previsível a partir desse ponto.
